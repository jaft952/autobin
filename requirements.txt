# pip install -r requirements.txt

# torch/torchvision are NOT pinned to a platform build here — `pip install
# torch` picks whatever your platform's default PyPI wheel is, and that can
# be WRONG for this project's two real targets:
#
#   -> Raspberry Pi / any ARM Linux board (no NVIDIA GPU) — MUST be CPU-only.
#      A CUDA build (torch==X.Y.Z+cuNNN) still IMPORTS fine but SIGILLs the
#      instant it runs real math (matmul/conv) — its CPU kernels use
#      instructions this chip doesn't have. Diagnosed 2026-07-18 with
#      tests/diagnose_runtime.py after test_ibvs_centering/test_arc_grasp
#      both died with "Illegal instruction" during YOLO's first .predict.
#      Install explicitly (don't rely on the default index):
#          pip uninstall -y torch torchvision
#          pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
#
#   -> Windows with an NVIDIA GPU and want CUDA? install torch separately:
#      pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
#
# If neither applies (plain CPU dev machine), the `torch>=2.0.0` line below
# is fine as-is.
